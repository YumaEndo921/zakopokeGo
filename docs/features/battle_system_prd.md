# NPCトレーナーバトル機能 要件定義書 (PRD)

## 1. 概要と目的
- **現状の課題**: 現在のアプリはポケモンを捕まえて集めるだけで、捕まえた後の楽しみ（ユーティリティ）が少ない。
- **解決策**: 捕まえたポケモンを使ってNPCトレーナーと戦える「バトル機能」を実装する。
- **期待する価値**: ポケモンを育てる、戦わせるという新しい体験を提供し、継続的なプレイ動機と愛着を生み出す。

## 2. ユーザーストーリー
- [ ] **メインシナリオ**: ユーザは、自分のポケモン1体を選んでNPCトレーナーとバトルし、コマンド選択で勝利を目指す。
- [ ] **成長シナリオ**: バトルに勝つと経験値を取得し、レベルアップすることでポケモンが強くなる。
- [ ] **戦略シナリオ**: 相手のタイプに合わせて相性の良いポケモンや技を使い、バトルを有利に進める。

## 3. UI/UXにおける「可愛さ（Aesthetic）」の要点
- バトルのログ（「〇〇の こうげき！」）をポップなフォントと色使いで表示し、動き（シェイクなど）を加える。
- レベルアップ時にキラキラしたエフェクトとともに「おめでとう！」という演出を出す。
- コマンドボタンは現在のUI（丸みのあるデザイン）を踏襲し、押し心地の良いものにする。

## 4. 受け入れ条件 (Acceptance Criteria)
- [ ] 1. 捕獲時にPokeAPIからそのポケモンが覚える技を1つランダムに取得し、DBに保存されること。
- [ ] 2. `/battle` 画面でNPCのポケモン（ランダム選出）と交互に戦い、HPを削り合えること。
- [ ] 3. タイプ相性（2倍、0.5倍など）がダメージ計算に正しく反映され、メッセージが表示されること。
- [ ] 4. 勝利時に経験値が加算され、規定値に達するとレベルが1上がり、HP/攻撃力が上昇すること。
- [ ] 5. バトルの途中で「にげる」ことができ、その場合はデメリットなしでフィールドに戻ること。

## 5. スコープ外 (Out of Scope)
- 3体 vs 3体などのチームバトル（今回は1対1のみ）。
- 回復アイテムの使用（まずは攻撃と逃げるのみ）。
- オンライン対戦（NPCのみ）。

## 6. 懸念点 / 未決定事項
- PokeAPIから技を取得する際、攻撃技でないもの（「かたくなる」等）をどう除外するか。
- レベルアップに必要な経験値曲線をどう設定するか（シンプルに一定値にするか）。
- NPCトレーナーの強さ（レベル）をどう決めるか。
