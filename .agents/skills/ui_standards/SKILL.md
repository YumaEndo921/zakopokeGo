# UI & UX Standards Skill

このプロジェクトは「ギャル（chatGPT）と一緒に作ったチープで可愛いアプリ」という世界観を持っています。AIがUIを改修・追加する際は、以下の美学（Aesthetic）と技術的基準に従ってください。

## デザインの美学（Aesthetic）

- **カラーパレット**: ビビッドなピンク、パステルカラー、絵文字を積極的に活用してください。
- **インタラクション**: アニメーション（モンスターボールが揺れるなど）を重視し、ユーザーが「おっ」と思うマイクロインタラクションを追加してください。
- **フォント**: ブラウザ感のある標準的なフォントだけでなく、モダンなタイポグラフィの適用を検討してください。

## テンプレート実装ルール (`templates/`)

- **html/template**: Goの標準テンプレートエンジンを使用します。
- **共通レイアウト**: 現在は各ファイルが独立していますが、将来的に `layout.html` を作成し、ヘッダーやフッターを共通化することを推奨します。
- **静的資産のパス**: 画像やCSSは `/static/` パスで参照してください。
- **レスポンシブ**: スマートフォンでの操作を前提としたモバイルフレンドリーなレイアウトを意識してください。

## 静的資産の管理 (`static/`)

- 新しい画像が必要な場合は `generate_image` ツールを使用して生成し、`static/` 配下に保存して使用してください。
- CSSは各HTMLの `<style>` タグに書くのではなく、`static/style.css` に集約することを検討してください。

## 改修時のヒント

- **WOW要素**: 捕獲成功時やエラー時に、ただのテキストではなく視覚的な演出（パーティクル、グラデーション、大胆なフォントサイズ）を加えてください。
